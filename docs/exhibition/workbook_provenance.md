## 🔴 Limitation — no reproducible source

The workbook was generated by `scripts/build_master_workbook.py`. **The owner
decided on 2026-10-12 that the workbook is committed and the generator is
not.** `scripts/` is now gitignored.

### What that means

| Consequence | Detail |
|---|---|
| 🔴 **The workbook cannot be regenerated from this repository** | No source, no build command |
| 🔴 **It cannot be diffed meaningfully** | Binary. A one-character question change is invisible to `git diff` |
| 🔴 **Merges will not detect conflicts** | Two agents editing rows 400 and 401 of the same sheet will conflict silently |
| ⚠️ **Review is by opening it, not by reading a diff** | Honest review is possible, code review is not |

🔴 **This is a known, accepted trade-off.** The workbook is a *deliverable*; the
generator is *tooling*. The owner chose the artefact.

**If the workbook becomes load-bearing** — answers are entered, someone
iterates on it, two people edit it at once — 🔴 **the trade-off should be
revisited**, because silent merge conflicts in a school-facing form are a real
failure mode.
